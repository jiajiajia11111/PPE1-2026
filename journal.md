# Journal de bord du projet encadré

## Git et manipulation de fichiers

Aujourd'hui, j'ai travaillé sur la manipulation de fichiers avec le terminal et sur Git.

J'ai appris à organiser des fichiers dans différents dossiers avec des commandes comme `mkdir` et `mv`. Au début, j'ai eu un peu de mal à comprendre comment classer les fichiers selon leur date, surtout avec l'utilisation de `*`.

Ensuite, j'ai créé mon dépôt GitHub et je l'ai cloné sur mon ordinateur. J'ai utilisé `git status` pour vérifier l'état du dépôt, puis `git fetch` et `git pull` pour récupérer les modifications faites sur GitHub.

J'ai aussi utilisé `git log` pour voir l'historique des commits. Je comprends maintenant un peu mieux la différence entre le dépôt local sur mon ordinateur et le dépôt distant sur GitHub.
